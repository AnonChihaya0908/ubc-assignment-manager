后台运行

登录 Windows 后自动启动

在当前账户登录后静默启动后台。主窗口关闭后，仍可从系统托盘重新打开。

菜单栏图标

关闭主窗口后可从菜单栏重新打开应用。隐藏图标后仍可从 Dock 或应用菜单打开和退出。

关闭与退出

关闭主窗口只会隐藏窗口，课程同步与提醒继续运行。请使用系统托盘或“数据与退出”页面退出应用。

下载 macOS 安装包

应用通过 GitHub 公共 HTTPS API 检查并下载更新，无需安装 GitHub CLI 或登录 GitHub。临时网络错误会自动重试；更新会保留当前 Windows 账户下的课程、作业与提醒数据。

未完成标记

网站图标与目录红点

有待完成或已过日期但仍未完成的作业时显示。可在“待完成”和“已过日期”页找到对应项目；尚未开放和已完成作业不触发。

100% 自动完成

默认将成绩达到 100% 的作业自动归入“已完成”。手动标记始终优先，并可随时恢复自动判断。

默认启用

所有完成状态需要手动确认

开启后，达到 100% 的作业仍留在“待完成”，标记为“待确认”并排在最前，直到你手动确认完成。

个人微信每日提醒

使用 Server酱 Turbo 向你的个人微信发送一条每日作业汇总。作业名称和日期会经过该服务；电脑关机或应用退出时无法发送。

尚未配置密钥

默认关闭。开启后，个人备注会随作业名称和日期发送给 Server酱。

汇总已开放且未完成的作业。尚未开放的 WeBWorK 作业不会被当作截止提醒。如果今天的时间已过，启用后会发送一次今日汇总。

每日邮件提醒

使用你自己的 Gmail 发件账户和应用专用密码发送，无需部署服务器。应用不会索取邮箱主密码。连接后先向收件地址发送测试邮件，再启用定时提醒；邮件含课程、作业、截止时间和链接。

邮件从上方 Gmail 地址发往收件地址。电脑关机、睡眠或应用退出时无法准点发送；恢复后只补发当天的邮件，失败最多重试三次。

添加课程

支持 PrairieLearn 的 Assessments 页面和 UBC WeBWorK 课程首页。

已添加课程

作业类别来自课程页面的分组标题。请根据 syllabus 自行决定是否忽略；应用不会根据名称推断类别是否计分。忽略后仍保留成绩、日期和手动设置，但不进入默认列表、计数、红点或任何提醒。

登录与手动导入

登录窗口使用应用专用的登录资料。登录完成后可隐藏窗口，再从后台同步课程。

Windows 优先使用 Edge，未安装时使用 Chrome；Mac 默认使用内置 WebKit。

PrairieLearn 页面无法同步？粘贴作业表格

在已登录的浏览器中复制 PrairieLearn 作业表格，粘贴到下方导入。WeBWorK 请使用登录窗口同步。

备份与恢复

备份包含课程、缓存作业、优先级、个人备注、手动完成状态、手动提醒日期和普通设置。不会包含 Server酱 SendKey、Cookie、Edge 登录资料、发送记录；课程和作业网址中的查询参数会移除。

导出 JSON 备份

适合换电脑或在重要修改前保存。文件带有格式版本和内容范围说明。

未选择文件

导入会替换当前课程、作业和普通设置；写入前会在本机自动创建恢复点。现有 SendKey 和浏览器登录资料不会从文件导入，也不会被删除。

本地数据

作业清单、提醒设置与专用 Edge 登录资料保存在当前 Windows 账户的本地应用数据目录中，覆盖升级不会删除。关闭网页不会停止后台提醒。

退出应用

停止后台同步和 Windows 提醒。下次可双击 UBC作业管理工具.exe 重新打开。
