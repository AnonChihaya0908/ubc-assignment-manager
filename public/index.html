后台运行

登录 Windows 后自动启动

在当前账户登录后静默启动后台。主窗口关闭后，仍可从系统托盘重新打开。

关闭与退出

关闭主窗口只会隐藏窗口，课程同步与提醒继续运行。请使用系统托盘或“数据与退出”页面退出应用。

软件更新

正在检查 GitHub 更新…

应用内更新目前通过 GitHub CLI（gh）读取公开的 Release；请在本机安装 gh，访问失败时检查其登录状态。更新会保留应用目录中的 .local-data 作业与提醒数据。

未完成标记

网站图标与目录红点

有待完成或已过日期但仍未完成的作业时显示。可在“待完成”和“已过日期”页找到对应项目；尚未开放和已完成作业不触发。

100% 自动完成

默认将成绩达到 100% 的作业自动归入“已完成”。手动标记始终优先，并可随时恢复自动判断。

默认启用

所有完成状态需要手动确认

开启后，达到 100% 的作业仍留在“待完成”，标记为“待确认”并排在最前，直到你手动确认完成。

个人微信每日提醒

使用 Server酱 Turbo 向你的个人微信发送一条每日作业汇总。作业名称和日期会经过该服务；电脑关机或应用退出时无法发送。

尚未配置密钥

汇总已开放且未完成的作业。尚未开放的 WeBWorK 作业不会被当作截止提醒。如果今天的时间已过，启用后会发送一次今日汇总。
